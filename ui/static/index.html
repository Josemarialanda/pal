PAL cheat sheet 

  
Define a type system as inference rules, then ask PAL to infer types with it.


  
Statements

  
type Bool              -- declare a type
type Arrow<a, b>       -- a type with parameters
expr True : Bool       -- axiom: a constant and its type
rule Not:              -- an inference rule
  x : Bool             --   premises, one per line
->
  Not(x) : Bool        --   conclusion
infer Not(True)        -- infer an expression's type
check Not(True) : Bool -- expect a type (type variables may be renamed)
fails Not(Not)         -- expect a type error

  
Types must be declared before use, with the right number of arguments. A definition that breaks this, or a rule whose premise uses a variable missing from its conclusion, is rejected.


  
Premises

  
x : T                  -- x must have type T
x : A |- body : B      -- check body with x : A in scope
x : A, y : B |- e : C  -- several hypotheses
x : gen A |- body : B  -- x is polymorphic in body

  
⊢ works in place of |-.


  
Naming

  
    
    
  • Uppercase: constructors and concrete types, e.g. Add(x, y), Maybe<Num>
    • 
    
  • lowercase: variables and type variables, e.g. x, a
    • 
    
  • Comments start with --
    • 
  


  
Errors

  

    
Type mismatchTwo different types had to be equal

    
Arity mismatchA rule exists, but for a different number of arguments

    
Unknown expressionNo rule, no expr, and not a bound variable

    
Infinite typeA type would contain itself (a ~ Arrow<a, b>)

    
No typing rule matchedA constant was given arguments

    
undeclared typeDeclare it first with type
